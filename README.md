# sneakers-vault 🐹

> 🧭 Sneakers vault and workflow services: secrets, versions, rotation, heartbeat state and approvals (with their gRPC APIs)

## 📦 Install

```bash
go get github.com/Sneakers-PAM/sneakers-vault
```

## 🛠 Develop

```bash
task build    # go build ./...
task test     # go test ./...
task lint     # gofmt check + golangci-lint + yamllint
task license  # check Apache-2.0 headers (golic)
```
